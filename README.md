# 💰 Finanças Pessoais  

🚀 **Aplicação para gerenciamento de orçamento pessoal, desenvolvida com HTML, CSS, Bootstrap e JavaScript.**  

## 📌 Sobre o Projeto  
Este projeto foi criado para ajudar no controle financeiro, permitindo ao usuário adicionar despesas e receitas, visualizar o saldo disponível e organizar melhor suas finanças. Os dados são armazenados no **LocalStorage**, garantindo que as informações sejam mantidas mesmo após fechar o navegador.  

🔗 **Acesse o projeto:** [Clique aqui](https://lvambaster.github.io/Financias_Pessoais/)  

## 🛠 Tecnologias Utilizadas  
- **HTML5** → Estrutura da aplicação  
- **CSS3** → Estilização  
- **Bootstrap** → Layout responsivo e estilização avançada  
- **JavaScript** → Manipulação de dados e interatividade  
- **LocalStorage** → Armazenamento dos dados do usuário no navegador
